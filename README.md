# Neutron Star Collision Simulator

A simple browser-based visualization of a binary neutron star system, built with HTML5 Canvas and JavaScript.

## Features

* Binary neutron star orbital animation
* Collision flash effect
* Expanding shockwave rings
* Particle burst and glowing trails
* Post-merger remnant visualization
* Start, pause, and reset controls
* No external libraries required

## Requirements

* A modern web browser
* No installation or internet connection required to run the simulation

## How to Run

1. Download or clone this repository.
2. Open `notron-carpismasi.html` in your browser.
3. Click **Start** to begin the animation.

## Scientific Disclaimer

This project is a visual demonstration, not a numerical astrophysics simulation. It does not solve Einstein's field equations or relativistic hydrodynamics. The explosion, particles, and wave effects are illustrative and do not represent quantitatively calculated merger physics.
